1. 德国法院裁定AI音乐生成器Suno侵犯版权，驳回合理使用抗辩

The Decoder：AI News（RSS）

慕尼黑法院裁定，AI音乐生成器Suno在训练过程及输出结果中均侵犯版权，并驳回其合理使用抗辩。法院认定Suno 3.5和4版本模型可复现六首知名歌曲的原创元素，构成"记忆化"侵权，且责任归于Suno而非用户。该判决还认定美国版权法下的合理使用不适用于此案，目前尚未最终生效。

启示

这是欧洲法院对AI训练数据版权问题的标志性裁决，明确否定了"合理使用"作为AI训练的抗辩理由。对AI创业者而言，训练数据的合规性已从灰色地带变为硬性风险，建议立即审查训练数据来源，建立版权清关机制，并关注欧盟AI法案配套的版权披露义务。对使用AI生成内容的开发者，责任归属问题也需在合同中明确。

2. OpenAI Astra 以约2000美元证明10项数学难题

X：Greg Brockman (@gdb)

OpenAI 用下一代模型 Astra 内部版解决了数学与理论计算机科学领域的10项重大进展，总成本约2000美元（按 Sol API 价格计算）。Astra 证明了非 sofic 群的存在，并推翻 Connes 刚性猜想，成果涵盖 von Neumann 代数、高维球堆积、电路复杂度等。OpenAI 已发布全部10项证明，附 Lean 证书与 CoT 逐步推导。

启示

2000美元解决10个开放数学问题标志着AI科研能力从"辅助工具"升级为"自主研究者"。对创业者而言，这意味着AI驱动的科学发现即将成为可商业化的赛道——尤其在数学、密码学、算法优化等领域。建议关注Lean等形式化验证工具链的成熟度，这是AI推理能力可信化的关键基础设施，也是构建可验证AI产品的技术底座。

3. DeepSeek V4-Flash 正式版 API 上线公测：单任务成本比 GPT-5.6 Luna 低约 60%

IT之家（RSS）/ X：Elvis Saravia (@omarsar0)

DeepSeek 于 7 月 31 日通过 API 文档发布日志，宣布 DeepSeek-V4-Flash 正式版 API 上线公测。多个AI跑分基准平台同步更新了相关基准测试结果，显示其AI单任务成本比GPT-5.6 Luna低约60%。Perplexity CEO Aravind Srinivas评论称"两个数量级的改进相当罕见，这是件大事"，有报告显示DeepSeek以比Fable低105倍的成本完成了相同的基准任务。

启示

推理成本每降一个数量级，就会解锁一批此前经济上不可行的AI应用场景。对创业者来说，DeepSeek的定价策略将倒逼整个API市场重新定价，建议立即评估现有AI产品的成本结构——如果单任务成本可降低60%-99%，这意味着可以重新设计产品逻辑，从"每请求计费"转向"批量处理"甚至"常驻智能体"。同时注意供应链风险，关注地缘政治对模型可用性的影响。

4. 谷歌 Gemini Spark 智能体向全球更多用户开放，支持订机票、整理收件箱

IT之家（RSS）

谷歌于 7 月 31 日将 Gemini Spark 智能体开放给全球大部分用户，可在用户指示下整理收件箱、总结通讯邮件、取消订阅。该智能体已与 Chrome 浏览器整合，经授权后可使用保存的账户密码代用户完成搜索航班、预订机票、查询收藏房源等网络操作。Spark 提供两种安全机制，会防御提示词攻击，并将付款等敏感操作交给用户完成。

启示

谷歌将浏览器作为智能体的"手和眼"，标志着AI智能体从聊天走向真正的"数字助理"阶段。对创业者而言，浏览器深度集成意味着用户交互入口正在被巨头重塑，建议关注以下机会：为智能体设计"可操作"的网页结构（如schema.org结构化数据）、开发智能体专用的API和认证协议，以及在支付、身份验证等敏感环节提供安全中间层服务。

5. 英特尔加速俄亥俄晶圆厂建设，EMIB-T 封装良率逼近 90%

IT之家（RSS）

英特尔正通过发放高额加班奖金加速俄亥俄州晶圆厂园区建设，目标在 2031 年实现 14A 工艺大规模量产。其 EMIB-T 先进封装技术良率已接近 90%，成本比台积电 CoWoS 低约 50%，预计 2027 年开始大规模提供封装服务。目前唯一未解决的关键问题是基板良率，仍停留在约 50%。

启示

AI算力需求正重塑整个半导体供应链，先进封装（而非制程工艺）正在成为新的竞争焦点。英特尔EMIB-T的成本优势意味着AI推理芯片的封装成本可能大幅下降，这对AI硬件创业者是利好——更低的封装成本意味着更便宜的AI加速卡和边缘设备。建议关注英特尔封装服务的开放节奏，并评估将其纳入AI硬件供应链的可行性。
