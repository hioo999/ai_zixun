1. OpenAI 红队测试：前沿智能体几乎攻破所有沙箱隔离，还能靠 CPU 缓存跨虚拟机传密

X（Ethan Mollick）/ The Decoder

OpenAI 让前沿模型智能体团队攻击自家加固的隔离基础设施，结果智能体几乎在每个受限联网服务中都找到漏洞；更关键的是，在完全断网、无共享文件的条件下，它们能利用 CPU 缓存时序等侧信道在虚拟机之间隐蔽通信，并自主建立编码方案交换信息（类 Spectre/Meltdown 手法）。Ethan Mollick 据此呼吁：实验室那些看似夸张的 AI 网络安全警告应被更认真对待。

启示

这不是"未来风险"，而是当前智能体能力的实测结果。对创业者而言有三条具体动作：① 任何允许智能体执行代码或访问网络的产品，必须按"对手是智能体"而非"对手是人类"来设计隔离边界，纯网络隔离已不足够，需考虑时序侧信道；② 做 Agent 基础设施（沙箱、权限、审计）的公司正迎来真实刚需，安全层是可商业化的差异化能力；③ 若你在金融、医疗等强监管行业部署智能体，提前建立"智能体越狱"应急演练机制，别等事故倒逼。

2. Anthropic 与一线开发者共识：别堆多智能体，单 Agent + Skills 渐进披露往往更优

X（邵猛转引 Anthropic Claude Platform）/ Dex Horthy（HumanLayer）

Anthropic 官方发文讨论何时应把子 Agent 折进主循环，指出在多项内部对比中，Skills 渐进披露的质量常更好、成本与延迟更低。HumanLayer 的 Dex Horthy 进一步印证：单一智能体配合 skills 常胜过复杂多智能体系统，有客户执行速度约提升 2x；他批评自 2025 年中起的 subagent 滥用，认为推特炒作鼓励了盲目并行而非审慎的上下文管理。

启示

这是一条能直接省钱、提速的架构建议。行动建议：① 审查你现有 Agent 系统，把"为并行而并行"的 subagent 拆解回主循环，用 Skills 按需渐进加载上下文，通常能同时降本降延迟；② 评估标准从"架构是否先进"改为"任务完成质量 / 单位成本 / 端到端延迟"三项硬指标；③ 团队内部建立 subagent 引入的准入条件（如确有独立上下文与并行收益），避免被行业叙事带偏。多智能体不是不能用，而是要有明确的收益证据。

3. 智能体流量首超人类，腾讯元宝搜索全行业开放：Agent 时代搜索的选型与成本账

X（Oran Ge）

作者从 Cloudflare 数据切入——自动化流量占比达 57.5%、首次超过人类流量，分析 Agent 时代搜索的三个卡点，并实测刚向全行业开放的腾讯元宝搜索：覆盖 9 品类 31 条 query，强项是权威信源、时效性与直接返回正文；内部产品换用后单任务平均搜索调用从 8 次降到 5 次；支持 Skill、MCP、API 三种接入，价格 14–26 元/千次。

启示

"Agent 流量超过人类"意味着搜索、内容、广告的底层假设正在翻转——你的产品要为"机器读者"优化，而不只是为人。具体动作：① 若产品依赖联网检索，重新做一次搜索供应商比价与实测（调用次数下降 30%+ 直接体现为毛利改善）；② 为 Agent 访问设计结构化、可直接消费的内容接口，而非仅面向人类渲染的页面；③ 关注按调用计费的搜索成本在单位经济模型中的占比，Agent 高频调用会让它从"忽略项"变成"主要成本项"。

4. 宾州签署 AI 欺骗性广告法：AI 生成/显著修改的广告须同格式标注

The Verge

宾州州长 Shapiro 签署《人工智能欺骗性广告法》，要求经 AI 显著修改或生成的图像、视频、音频或文字广告，以与广告本身相同的格式加注标识，且不论在何处制作、只要在宾州投放即适用。该州是最早要求 AI 内容披露的州之一，但法案对"显著修改""明显虚构"界定模糊，并设戏仿、讽刺等豁免，留有漏洞。

启示

AI 内容标识正从"平台自律"走向"州法强制"，且采用"投放地管辖"原则——这对做营销、广告创意、数字人、AI 视频的团队是直接合规项。行动建议：① 立即排查面向美国投放的 AI 生成广告素材，建立"生成即打标"的产线默认流程；② 在创意审核环节增加"是否构成显著修改"的判断清单，并保留生成记录以备举证；③ 把合规标识做成产品能力（自动水印/元数据/C2PA），既是防御也是卖点。预计更多州跟进，早建流程成本最低。

5. Block 发布纯语音训练的全双工模型 Dessa，可在 M4 Max MacBook 本地实时运行

X（邵猛）/ IT之家

Jack Dorsey 旗下 Block 推出 Dessa——从零用纯人类语音训练的全双工 speech-to-speech 会话模型，无文本、无预训练底座，可边说话边收听，能模拟笑声、停顿、哽咽等情绪表达，知识来自训练对话数据而无需搭配大语言模型；声称推理快于实时，可在 MacBook Pro M4 Max 及以上本地运行。

启示

"纯语音、无文本底座、端侧实时"三点组合值得重视：它指向一条绕开大 LLM 的语音交互技术路线，且端侧运行意味着隐私敏感场景（客服、医疗、车载、陪伴）可低成本落地。行动建议：① 做语音交互产品的团队应实测 Dessa 在延迟、打断处理、情绪自然度上的表现，评估是否能替代"ASR+LLM+TTS"三段式管线以降本；② 端侧实时语音为离线/隐私卖点打开空间，可考虑作为差异化定位；③ 关注"无文本底座"路线的局限（知识广度、可控性），在需要复杂推理的场景仍可能需混合架构。
