1. SpaceX AI 算力业务收入超越 Starlink，成第一大收入来源；OpenAI 拟以超 1.4 万亿美元估值融资 300 亿美元

X（Rohan Paul）、TechCrunch

SpaceX 第三季度财报显示，"Super Intelligence"算力租赁业务收入达 76 亿美元（Q2 为 25.6 亿美元），占公司总收入 52%，首次超过 Starlink 连接业务，客户包括 Anthropic 和 Google。同一天，路透报道 OpenAI 正抢在 Anthropic 上市前洽谈约 300 亿美元融资，估值超 1.4 万亿美元，较 3 月的 8520 亿美元至少高出 64%。

启示

算力租赁已成为比卫星互联网更赚钱的生意，说明"卖铲子"的商业模式在 AI 时代具备极强的现金流确定性。对创业者而言，这印证了两点：一是算力供给仍是当前最稀缺的资源，围绕算力调度、能效优化、异构调度的基础设施层创业窗口依然开放；二是头部模型公司估值快速膨胀的同时，融资节奏明显被 IPO 竞争驱动，早期创业者在与巨头合作时应警惕"站队成本"——算力供应商与模型公司正从客户关系演变为竞争关系。

2. Anthropic IPO 草案曝光：上半年收入 163 亿美元，但承诺约 4500 亿美元算力支出，云厂商合作生变

X（Rohan Paul）、TechCrunch

WSJ 获取的 Anthropic S-1 草案显示，其上半年收入 163 亿美元、纸面亏损 807 亿美元，并承诺约 4500 亿美元的算力支出。同时文件披露，AWS、Google、微软日益将 Anthropic 视为竞争者而非客户，导致其难以获得足够云算力。

启示

这是一组极具警示意义的数字：收入 163 亿 vs 算力承诺 4500 亿，杠杆倍数接近 28 倍。对创业者而言，有两点直接教训：第一，模型公司正在用长期算力承诺换取短期训练能力，这种"重资产锁定"模式一旦收入增速不及预期，将面临巨大的现金流断裂风险；第二，云厂商与模型公司的竞合关系正在恶化，依赖单一云生态的 AI 创业公司应尽早设计多云或混合部署架构，避免在供应链谈判中失去议价权。

3. DeepSeek 开源内部推理框架 DeepInfer；蚂蚁与 vLLM 社区开源量化推理内核 Humming；llm-d 1.0 生产就绪

公众号 DeepSeek、vLLM 官方博客、IBM Research

DeepSeek 宣布全面开源其内部推理框架 DeepInfer，同步开源生产级 Token 编解码组件 deepseek-recipe。同日，蚂蚁集团与 vLLM 社区开源量化推理内核库 Humming；IBM、Red Hat、Google 主导的 Kubernetes 原生分布式推理框架 llm-d 发布 1.0，支持任意模型、任意加速器、任意云。

启示

推理层开源生态在一天内迎来三连发，信号非常明确：推理优化正从各家私有护城河变为公共基础设施。对 AI 创业者来说，这意味着推理成本还将继续下探，基于推理效率差异化的创业窗口正在收窄。更务实的策略是：尽快将自研推理栈迁移到这些开源方案上，把工程资源从"造轮子"转向"用轮子做场景"；同时关注 llm-d 这类 K8s 原生方案，它降低了中小团队自建分布式推理集群的门槛，适合有多云部署需求的团队优先评估。

4. OpenAI API 支持 12 小时 prompt 缓存，Codex 与 Work 用户缓存永久保留

X（Tibo）

OpenAI 开发者账号宣布 API 现已支持可选的 12 小时 prompt 缓存，持续运行的智能体可在请求间隔数小时的情况下，以更低的缓存输入费率复用指令、工具和上下文。Codex 与 Work 中已登录用户的缓存永久保留，返回旧对话或数小时后恢复会话保证命中缓存，且无额外惩罚。

启示

12 小时缓存对长时间运行的 Agent 产品是实质性利好——此前多数 Agent 框架需要自行实现上下文压缩或外部记忆，现在可以直接依赖 API 层缓存降低长会话成本。建议做 Agent 产品的团队立即做两件事：一是重新测算长会话场景的 token 成本模型，缓存命中率可能让单位经济模型发生质变；二是重新评估是否还需要自建向量记忆层，部分场景下 API 原生缓存可以替代。对做个人助理、客服、编程助手类产品的团队，这是本周最值得动手测试的更新。

5. Perplexity Computer 实现 Mac 完全本地运行；面壁智能 35B MoE 在手机端侧实时无损运行

X（Aravind Srinivas）、公众号 面壁智能

Perplexity CEO 宣布 Perplexity Computer 现可在 Mac 上完全本地运行，无需云端推理和 WiFi，模型与智能体均在本机运行，可操作 Mac 原生应用和本地文件，敏感数据不出设备。同日，面壁智能介绍其前瞻专家调度（LES）技术，首次实现 35B-A3B 规模 MoE 在端侧实时无损运行，iPhone 18 Pro Max 实测解码超 20 token/s。

启示

端侧 AI 在同一天取得两个标志性进展：一是 Agent 级产品（不只是模型）实现完全本地化，二是 35B 级 MoE 在手机上达到可用速度。对创业者而言，这打开了两个明确的产品方向：面向隐私敏感行业（医疗、法律、金融）的本地 Agent 工具，以及不依赖网络连接的离线 AI 应用。建议关注端侧推理的团队重点评估 LES 这类专家调度方案，它让"大模型上手机"从演示走向产品；同时注意，本地化意味着分发渠道和商业模式可能从订阅 API 转向一次性授权或硬件捆绑。
