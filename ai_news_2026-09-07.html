1. OpenAI 官宣自动化研究实习生达成，内部 Agent 运行量已达人力 3.1 倍

OpenAI 官网 / X：Rohan Paul

OpenAI 发文披露内部研究加速进展，宣布已达成去年设定的"自动化研究实习生"里程碑——可在人类监督下完成需数天的明确研究任务。截至 8 月中旬，其研究组织每投入 1 个人工工作日，就运行 3.1 个 agent 工作日，并计划在 2028 年 3 月前实现自动化 AI 研究员。OpenAI 首席科学家 Jakub Pachocki 同步发文，预期进展将走向机器递归自我改进（RSI）。

启示

3.1 倍运行时长只是起点，真正的拐点是 agent 从"辅助工具"变为"研究协作者"。AI 从业者应尽早将工作流拆解为可并行、可委托给 agent 的模块，而非观望。对创业者而言，"AI 研究员"的中间形态（半自动、需人类补全判断）本身就是巨大的产品机会——为专业领域构建带监督的 agent 闭环，比追求全自动更早落地。

2. GPT-6 Astra 实测：自主操控专业软件完成数天级任务，执行能力贬值与判断力断层显现

公众号：数字生命卡兹克

GPT-6 Astra 上线后，大量用户用它自主操控 Blender、Houdini、Unity、Aseprite 等专业软件完成复杂作品——包括 3D 复刻旧金山艺术宫，其中 Astra 自行搜索数百张参考图、翻到美国国会图书馆的老扫描文件找柱子尺寸，多数工作在夜间自主完成。作者卡兹克指出，执行能力正在快速贬值，而"判断力"成为新的稀缺能力。

启示

当 AI 能通宵完成执行层工作，"知道什么值得做、什么算做好"成为人的核心价值。对从业者：与其焦虑被替代，不如刻意训练自己的品味与判断力——这是 AI 短期内最难复制的。对创业者：面向"AI 执行+人类判断"协作模式的基础设施（如任务校验、质量评估工具）是确定性需求。

3. 黄仁勋官宣"AGI 已到来"，GPT-6 Astra 由 10 万+ Blackwell GPU 训练；Gary Marcus 质疑无定义无证据

IT之家 / Gary Marcus：The Road to AI We Can Trust / X：Greg Brockman

黄仁勋在 X 上祝贺 OpenAI 发布 GPT-6 Astra，称从 ChatGPT 到 o1 再到 Astra 仅用 4 年，AGI 已经到来，并透露 Astra 由约 10 万+ NVIDIA Grace Blackwell NVLink72 训练，下一批 40 万 GPU 即将上线。OpenAI 总裁 Greg Brockman 回应"欢迎来到 AGI 时代"。然而认知科学家 Gary Marcus 撰文批评黄仁勋未给出任何定义和证据，建议参考 agidefinition.AI 的严肃讨论。

启示

"AGI 已到来"的叙事会加速资本与人才向 AI 领域集中，也会影响监管节奏与客户预期。对创业者：不必纠结于 AGI 的定义之争，而应关注"能力跃迁真实发生"这一事实——10 万卡训练的前沿模型意味着能力上限再次大幅提升。务实策略：基于当前可用的最强模型设计产品，同时为"定义尚不明确"的监管环境预留合规弹性。

4. OpenAI 长文自曝对齐困境：CoT 监控能力随模型变强而减弱，呼吁自愿放缓扩展

OpenAI 官网

OpenAI 发布长文《An Alien Mind》，系统阐述目标对齐与价值对齐的区分，坦承链式思维（CoT）监控的效果正随着模型能力提升而逐步减弱。文章指出 GPT-6 Astra 在对齐上显著优于前代，但预期进展可能走向机器递归自我改进（RSI），并罕见地呼吁自愿放缓扩展、建立第三方安全门槛、加强国际协调。

启示

前沿实验室公开承认"监控手段在失效"，说明对齐问题没有简单解。对 AI 从业者：在构建 agent 系统时，不要默认"模型越强越安全"——需要设计独立于模型自述的验证机制（如外部工具校验、人工抽检）。对创业者：安全对齐与可观测性工具（尤其是针对长时程自主任务）将是未来两年的高价值赛道。

5. Anthropic 15 亿美元版权和解金开始发放，分配争议不断；Seattle Times 与 Newsday 再诉 OpenAI 与微软

TechCrunch：AI（RSS） / IT之家 / The Verge

Anthropic 15 亿美元版权和解金进入发放阶段，法院认定训练模型属合理使用，但盗版获取的近 50 万部作品每部赔偿原作者 3000 美元。然而出版商和文学经纪被指超额认领不属于自己的份额，引发作者群体强烈反弹。与此同时，Seattle Times 与 Newsday 起诉 OpenAI 与微软，指控其未经许可使用新闻报道训练并在用户提问时复现原文段落。

启示

版权问题正从"训练是否合法"转向"利益如何分配"，数据合规的灰色空间在快速收窄。对创业者：使用任何第三方数据训练或做 RAG 前，务必完成版权链条审计——诉讼风险已从大厂蔓延到整个生态。对从业者：涉及内容生成的 AI 产品，应在设计阶段就内置"来源追溯"与"内容比对"机制，这既是合规要求，也是建立用户信任的差异化优势。
