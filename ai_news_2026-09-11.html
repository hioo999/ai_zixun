1. DeepSeek 发布 V4.1-Flash：552B MoE + 1M 上下文，KV Cache 暴降，API 同步降价

DeepSeek API 更新日志 / MarkTechPost / The Decoder / SiliconFlow

DeepSeek 发布全新架构系列的最小模型 V4.1-Flash，采用 Causal Encoder-Decoder 架构，552B MoE 主干 + 196B Engram 参数，prefill 激活约 8B、decode 激活约 16B，支持原生多模态视觉理解与 1M 上下文窗口。全局 KV cache 降至每 token 890 字节，约为上代的 1/4、V1 的 1/437，并采用 FP4 KV 缓存与跨层注意力复用，MIT 许可开源。评测成绩包括 GPQA Diamond 90.9、HLE 36.8、Codeforces 3471、Terminal-Bench 2.1 90.6。API 价格同步下调，硅基流动等平台 Day 0 上线，WorkBuddy 提供两周免费试用。

启示

KV cache 降至 1/4 意味着同等显存下可支撑的并发 Agent 会话数提升约 4 倍，长上下文 Agent 的单次任务成本将出现结构性下降——建议立即用 V4.1-Flash 重跑你现有的 Agent 工作流，重新测算每任务成本，此前因成本被砍掉的长上下文场景（如全代码库理解、长文档多轮推理）现在值得重新评估。MIT 许可 + 原生视觉 + 1M 上下文，使"自部署多模态长上下文模型"首次具备商业可行性，做垂直行业 Agent 的团队应认真评估私有化部署方案。

3. Cursor 推出 Projects：协调者智能体调度数千子智能体，处理大型开发任务

Cursor Blog

Cursor 发布 Projects（beta），用户可通过协调者智能体处理功能开发、代码迁移和持续性维护等大型工作。协调者本身不写代码，而是调度数千个子智能体并行执行，将"多智能体编排"从实验推向了工程化产品。

启示

"协调者不写代码、只做调度"这一设计明确了多智能体架构的分工范式：编排层的价值在于任务分解、上下文分配与结果校验，而非生成能力本身。对做 AI 编程工具或 Agent 平台的团队，这是一个可直接借鉴的架构模板；对使用方而言，大型重构/迁移类项目（此前因上下文窗口和一致性难以交给 AI）现在可以尝试用 Projects 模式拆解。建议关注其子智能体间的冲突解决机制和成本控制策略——这两点决定了该模式能否从 beta 走向生产可用。
