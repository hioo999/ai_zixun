1. DeepSeek 接近完成 120 亿美元融资，腾讯与宁德时代领投，计划 2027 年 IPO

Bloomberg / X：X.PIN

据 Bloomberg 报道，DeepSeek 接近完成至少 800 亿元人民币（约 120 亿美元）融资，远超原定 500 亿元目标。腾讯和宁德时代是本轮最大投资方，融资预计很快完成，DeepSeek 还计划 2027 年初 IPO。同日 ARC Prize 公布 DeepSeek V4.1 Flash 在 ARC-AGI-2 上得分 72.9%（每任务 $0.13），推理能力较上代大幅提升。

启示

120 亿美元的融资规模意味着 DeepSeek 将获得充足的算力和人才弹药，其开源+低价策略会进一步挤压中小模型公司的生存空间。对创业者而言，基于 DeepSeek 做应用层的窗口期仍在，但需警惕其自身向应用层延伸的可能。另外，V4.1 Flash 推理能力跃升但成本增加 250%，说明"更强推理"与"更低成本"的权衡仍是产品设计的关键决策点——不是所有场景都需要最强推理。

2. Mistral Large 4 全面上线：1T 参数、512K 上下文、原生多模态，开放权重

OpenRouter / Arena

Mistral Large 4 在 OpenRouter 开放公测，规格为 1T 参数（49B 激活）、原生多模态、512K 上下文、最高 256K 输出。前两周五折：每 1M tokens 输入 $0.68、输出 $2.09。同时在 Arena 的 Code Arena WebDev 排名第 45（得分 1534），较 Mistral Large 3 提升 304 分，并已进入 Agent Arena 评测。

启示

1T 参数开放权重模型的出现，意味着开源模型的能力天花板再次被抬高。49B 激活的 MoE 架构使推理成本可控，而 512K 上下文为长文档处理、大型代码库理解等场景提供了新可能。建议开发者立即在 OpenRouter 上以五折价格测试该模型在你核心场景中的表现，尤其是需要长上下文+多模态的任务。如果效果接近闭源模型，可显著降低 API 成本。

3. Sierra 与 Meta 联合 Shopify、Stripe、Walmart 发布 Personal Agent Protocol 开放协议

Sierra Blog

Sierra 与 Meta 联合 Genesys、Instinct、Rocket、Shopify、Stripe、Walmart 等企业宣布开发 Personal Agent Protocol，定义个人 AI 智能体如何与企业交互的开放标准，任何人都可实现。与此同时，GitHub 宣布重建 Git 基础设施以应对智能体规模开发——9 月智能体和开发者产生 73.8 亿次 commits，pushes 同比增长 4.9 倍。

启示

这是"智能体互联网"基础设施成型的强烈信号。当个人 Agent 需要代表用户与企业系统交互时，没有统一协议就意味着每家企业都要单独适配——PAP 试图解决这个问题。对创业者而言，如果你的产品涉及 Agent 与企业服务的对接（如电商下单、客服、支付），应尽早关注并参与 PAP 生态。GitHub 的数据则从另一个侧面印证：Agent 驱动的开发行为正在指数级增长，围绕 Agent 开发工具链的创业机会巨大。

4. OpenAI 发布内部前沿模型产出的数学研究成果，证明已用 Lean 形式化验证

OpenAI 官网

启示

AI 产出经 Lean 形式化验证的数学证明，意味着 AI 在严谨推理领域已跨过"可信"门槛。这对从业者的启示有两层：一是 AI for Science 的商业模式正在成熟，尤其在需要形式化验证的领域（芯片验证、密码学、协议设计）；二是如果你的产品涉及代码生成，Lean 形式化验证的思路值得借鉴——用可验证的输出替代"看起来对"的输出，是提升 AI 产品可靠性的关键路径。
