4. 研究人员发现可读取 ChatGPT 等模型加密推理过程的 API 漏洞

The Decoder

Alexander Panfilov 团队发现 OpenAI、Anthropic、Google 等主要 AI 提供商 API 存在漏洞，可读取推理模型的加密思考过程。扫描约 7000 条公开会话发现 62 个 API 密钥、33 个邮箱和 33 个密码；通过越狱，Anthropic 的 Haiku 4.5 可逐字转写 Opus 4.8 的原始推理，解码 10000 条推理轨迹的 API 成本约 720 美元。

启示

推理过程的"加密"并非绝对安全，这对依赖 API 构建应用的团队是重要安全警示：不要在提示词或推理上下文中放入敏感数据。同时，该漏洞也暴露了推理模型的"思维链"可被提取——对于依赖私有推理逻辑构建产品壁垒的团队，需要重新评估护城河的有效性。建议立即审查自身 API 调用链路，排查密钥泄露风险，并关注各厂商的修复进展。
