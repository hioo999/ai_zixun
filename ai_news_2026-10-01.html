MarkTechPost / Artificial Analysis / Arena

OpenAI 发布 GPT-6.1 Sol，定价为每百万 token 2 美元输入、10 美元输出、0.10 美元缓存输入，仅为 GPT-6 Astra 标准价格约五分之一。Artificial Analysis 数据显示其 Cost per Task 约 $0.72，比 GPT-6 Sol 低约 30%。在 Code Arena: WebDev 榜单上，GPT-6.1 Sol (Max) 以 1759 分位列第 3，相比同价位的 GPT-6 Sol (Max) 提升 70 分、排名上升 4 位，且在 Consumer Product 等所有类目均有提升。

启示

模型竞争已从"谁最强"转向"谁在质量门槛之上最便宜"。GPT-6.1 Sol 证明中端价位可以逼近旗舰能力，这意味着依赖单一顶级模型的套壳产品利润空间将被进一步压缩。建议创业者重新核算推理成本结构，把省下的成本投入到产品差异化和数据飞轮上，而非继续为边际质量提升支付溢价。

2. OpenRouter 连发三篇实战指南：Agent 模型的成本、质量与置信度路由方法论

OpenRouter

OpenRouter 发布三篇面向 Agent 开发者的实战指南：（1）三步选型框架——先设质量门槛，再用 20-50 条自有示例跑廉价/中档/前沿模型，计算"每质量点成本"，选出以超过运行间分数波动余量过线的最便宜模型；（2）CI 中用固定 eval 集门禁 Pull Request，通过率低于阈值即以非零退出码阻止合并；（3）置信度阈值分级升级路由——让廉价模型返回 0-1 置信度，低置信度请求升级到更强模型，并强调置信分数只是自报、需按自己流量的分数段错误率排序设阈值。

启示

这三篇构成了一套可直接落地的"Agent 成本工程"方法论。核心信号是：按排行榜选模型的粗放做法已经过时，精细化路由才是降本关键。建议本周就在自己的 Agent 流水线里加一道 eval 门禁（成本极低、收益立竿见影），并用 50 条真实请求跑一次三档模型对比，你大概率会发现 60% 以上的请求用廉价模型即可达标。

3. ChatGPT 可直接构建并部署 MCP 服务器，Perplexity 开放邮件委托——Agent 分发入口之争白热化

X (@thsottiaux) / X (@AravSrinivas)

ChatGPT Sites 现在可以托管 MCP 服务器，用户可直接在 ChatGPT 中构建并部署，还能转为插件安装到 web、移动端和桌面端，支持限制访问权限或公开分享。与此同时，Perplexity 向所有人开放 Computer 的邮件委托功能，无需账号，转发或抄送任务到 computer@perplexity.com 即可限时免费运行，智能体在后台完成并保留邮件上下文，带完整审计记录。

启示

两个动作指向同一趋势：AI 平台正在把"构建 Agent"和"触达用户"的门槛降到接近于零。MCP 服务器托管在 ChatGPT 内意味着插件生态的冷启动成本大幅降低；邮件作为 Agent 入口则绕过了 App 安装这一最大摩擦。对创业者而言，现在应优先考虑"在别人的 Agent 平台上做分发"，而非自建入口——先用 MCP 插件或邮件委托验证需求，再决定是否投入独立产品。
