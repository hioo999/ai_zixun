1. OpenAI 年化营收逼近 500 亿美元但低于预期，引发科技股震荡

IT之家·人工智能

据金融时报报道，OpenAI 向投资者披露截至9月底年化营收接近500亿美元，大幅低于外界此前估算的700亿美元，缺口约200亿美元。差异主要源于统计口径——Anthropic 计入 AWS 和谷歌云等合作方销售收入，而 OpenAI 剔除了该部分。消息发布后纳斯达克100指数收跌1.4%，英伟达跌2.9%，甲骨文跌5.5%。

启示

这条新闻揭示了两个关键信号：一是大模型公司的真实营收可能被市场系统性高估，创业者做商业计划时不应盲目对标头部公司的"传闻数字"；二是统计口径差异（是否计入云厂商分成）正在成为行业估值的新变量。建议创业者在融资叙事中明确收入确认方式，避免因口径问题在尽调阶段被质疑。

2. Arena 完成 2 亿美元 B 轮融资，估值 31 亿美元并推出 Alignment Index

X：Arena (@arena)（多条合并）

Arena 完成由 Lightspeed 和 Khosla Ventures 联合领投的 2 亿美元 B 轮融资，估值达 31 亿美元，a16z、Salesforce Ventures 等参投。平台累计 3.5 亿场次会话、6200 万次投票，年化收入超 1 亿美元，约 5 个月内产生 700 万次 Agent Arena 会话。同时发布基于真实智能体轨迹的 Alignment Index，从 Unauthorized Action、False Attribution 和 Deceptive Completion 三个维度评估 20 多个前沿模型。

启示

Arena 的崛起说明"模型评测"本身正在成为一门大生意——从学术项目到 31 亿美元估值仅用约两年。对创业者而言，Agent 评测（而非传统 benchmark）是当前明显的空白赛道，尤其是基于真实使用轨迹的行为对齐评估。如果你在做 Agent 产品，建议尽早接入 Alignment Index 类工具，既作为自我审计手段，也可作为向企业客户证明安全性的差异化卖点。

3. 一条提示词即可劫持 AWS 账户内全部 AgentCore 智能体

The Decoder：AI News（RSS）

Zenity Labs 披露名为 AgentCorruption 的漏洞链：只需对一个公开的 Amazon Bedrock AgentCore 智能体发送一条提示词，即可通过元数据服务 169.254.169.254 窃取其 AWS 凭据，进而控制同账户同区域内所有 AgentCore 智能体，读取私人对话、源代码和存储凭据，并能篡改长期记忆。同日 Crowdstrike 报告疑似单人使用 AI 渗透工具 ARTEX 攻击多家韩国银行，Shinhan Bank 超 25,000 条记录泄露。

启示

这两条新闻叠加释放了强烈信号：AI Agent 的安全攻击面远大于传统应用——元数据服务、长期记忆、跨 Agent 信任链都是薄弱环节。如果你的产品部署在 AWS AgentCore 或其他托管 Agent 平台上，建议立即检查：① Agent 是否绑定了过宽的 IAM 角色；② 是否禁用了 IMDSv1；③ 长期记忆是否有写入审计。同时，AI 驱动的攻击工具已将攻击门槛降到"单人可操作"，安全预算不再是可选项。
